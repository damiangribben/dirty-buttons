## Question

Which input components make up the piece?

## Resolution

Seven components:

1. Push button
2. 3×3 grid of square buttons, like a sample pad (each pad gathers patina independently)
3. Click toggle switch (clicky rocker/bat)
4. Slide toggle switch
5. Slider with click stops
6. Label + text input; clicking the label opens a tooltip
7. Rotary dial
