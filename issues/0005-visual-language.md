## Question

What material are the components "made of" — which decides what dirt and wear look like?

## Resolution

- **Skeuomorphic** is the leading direction; a **flat modern** style is to be compared alongside it.
- **Patina is a layer independent of style**: touch history is data, drawn over whichever style is active, so switching style re-paints the same history.
- A **style switcher** control panel is always built in. It is a tool for the author, and its visibility is a single publish-time flag — hide it for live, or leave it visible.
- Which style ships is decided in [Which style should ship — skeuomorphic or flat?](0011-style-comparison.md).

> **Amended** by [Which style should ship — skeuomorphic or flat?](0011-style-comparison.md): skeuomorphic ships; flat and the style switcher are dropped.
