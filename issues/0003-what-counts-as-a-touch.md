## Question

What interaction adds patina to each component, and where does it land?

## Resolution

Every touch is recorded **at its position** on the component.

| Component | Touch |
|---|---|
| Push button | each press, at the pointer position |
| Sample pad | each press of an individual pad, at the pointer position on that pad |
| Click toggle | each flip |
| Slide toggle | each flip; wear along the thumb's path |
| Slider | **travel**: the track wears where the thumb travels most — heavy use in the middle leaves the ends clean |
| Label + input | the **focus click** position in the input (start / middle / end of the field) — not keystrokes. Label: each tooltip click |
| Rotary dial | undecided — see [How should the rotary dial wear?](0012-rotary-dial-wear.md) |

Hover and hold duration do **not** count.

> **Amended** by [How should the rotary dial wear?](0012-rotary-dial-wear.md): the dial's touch is a grab on the rim (stored relative to the knob); turning wears the index mark; the panel ring around the knob smudges on grab and its tick wears where the dial is left.
